# Interval Mode

Interval mode takes evenly spaced frames across the whole clip.

Under **Interval**, choose the unit:

- **Seconds** — one frame every *N* seconds. Good for long recordings where you want a steady overview.
- **Frames** — one frame every *N* frames. Good when you need precise, frame-accurate spacing.

Type the number in the field next to it. The line above the **Export** button updates right away with how many frames will be exported, so you can adjust the interval before writing anything.

**Tip:** start with a larger interval to get an overview, then switch to Manual mode to pick out the exact moments that matter.
