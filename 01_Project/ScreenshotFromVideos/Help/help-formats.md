# Formats and Quality

Choose the image format under **Format** in the right-hand panel.

| Format | Best for |
|---|---|
| **PNG** | Exact, lossless copies. Largest files. A safe default for screen recordings. |
| **JPG** | Small files that open everywhere. Some quality loss. |
| **HEIC** | Smaller than JPG at similar quality. Opens on Apple devices; less widely supported elsewhere. |
| **WebP** | Small files for the web and for uploading to tools and assistants. |

## Quality

For JPG, HEIC and WebP, the **Quality** slider trades file size against image quality. Higher means better-looking, larger files.

## Lossless WebP

With **WebP** selected, turn on **Lossless** to keep the image visually identical to the source while still getting files much smaller than PNG — typically about half the size. The slider then becomes **Effort**: higher effort produces slightly smaller files but takes longer to export.

All stills are written at the video's full resolution.
