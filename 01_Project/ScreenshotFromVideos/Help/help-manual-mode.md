# Manual Mode

Manual mode exports only the frames you choose.

## Capturing frames

- Click **Capture this frame** below the player to add the frame that's currently showing.
- Or press **Q** (or **M**) while the thumbnail strip is focused.
- Or **Command-click** any thumbnail to capture that exact frame without moving the playhead.

The counter next to the button shows how many frames you've captured. Thumbnails you've captured are marked in the strip.

## The list of captured frames

Captured frames appear under **Manual timestamps** in the right-hand panel, always sorted from earliest to latest — the same order they'll be written to disk. Each one is shown as hours:minutes:seconds:frames.

- To remove one, click the **x** button next to it.
- Capturing the same moment twice adds it only once.

## Copying a single frame

Click **Copy** under the player (Command-C) to put the current frame, at full resolution, on the clipboard. You can paste it straight into another app without exporting anything.
