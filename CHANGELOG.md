# Changelog

## 1.0 (build 1000) — first release

Turn a video into a folder of stills, ready to drop into a prompt, a bug report or a doc.

- **Two modes:** *Interval* (every N frames or every N seconds) or *Manual* (scrub and capture exact moments).
- **Thumbnail strip scrubber** with zoom; capture the frame under the playhead (Q or M), or copy it full-resolution to the clipboard.
- **Timestamp burn-in** in any corner with adjustable size, previewed live on the player before export.
- **Filename patterns** built from tap-to-insert tokens (`{name}`, `{counter}`, `{timecode}`, `{frame}`, `{seconds}`, `{date}`, `{time}`, …) with chronological numbering so files sort correctly in Finder.
- **PNG, JPG, HEIC and WebP** export with a quality slider (WebP lossless too).
- **Frame-count preview** in the footer, so you know what you'll get before exporting.
- **Honest error reporting:** a missing, read-only or failing output folder is reported instead of silently writing nothing.
- **Light, Dark or Match System** appearance, a built-in Help menu, Send Feedback and Leave a Tip.
- **Automatic updates** via Sparkle.

Requires macOS 15.0 or later.
