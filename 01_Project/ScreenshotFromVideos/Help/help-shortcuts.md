# Keyboard Shortcuts

## Anywhere in the app

| Shortcut | Action |
|---|---|
| Command-O | Open a video |
| Command-C | Copy the current frame to the clipboard |
| Command-Return | Export |
| Escape | Cancel a running export |
| Command-Equals | Zoom the strip in |
| Command-Minus | Zoom the strip out |
| Command-0 | Reset the strip zoom |
| Command-Question Mark | Open this help |

## When the thumbnail strip is focused

Click the strip once to focus it.

| Key | Action |
|---|---|
| Q or M | Capture the current frame |
| Left Arrow / Right Arrow | Previous / next thumbnail |
| Up Arrow / Down Arrow | Up / down one row |
| Option-Left Arrow / Option-Right Arrow | Jump back / forward 30 seconds |
| Shift-Left Arrow / Shift-Right Arrow | Jump back / forward 1 minute |
| Home / End | First / last thumbnail |
| Page Up / Page Down | Up / down one screenful |
| Space | Play or pause |
| J / K / L | Play backwards / pause / play forwards; press J or L again to go faster |
| + / − / 0 | Zoom in / zoom out / reset zoom |

## With the mouse

| Action | Result |
|---|---|
| Click a thumbnail | Jump to that frame |
| Command-click a thumbnail | Capture that frame |
| Command-scroll over the strip | Zoom the strip |
